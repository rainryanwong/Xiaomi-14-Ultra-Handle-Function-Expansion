# 6.8 相机移植后续事项

## 徕卡经典多 LUT 扩展到其他模式

- 2026-11-22，目标相机 `6.8.001770.0`。HandleFix 的录像键短按按相机进程中 CameraCompat 公布的模式开放，`0.1.184` 的模式为 163、167、168、171、173、225、228、229、230。
- 229 可以单独设置多 LUT，未单独设置时继承普通街拍（225）。其余按键继承规则继续沿用。
- CameraCompat 后续扩展模式时，逐模式确认相机内选风格能同时更新取景和 MIVI 成片所用的 LUT。HandleFix 复用接口公布的模式，并在新模式缺少配置行时补齐对应入口。检查从手柄切换后，相机风格选择页读回、取景和保存的照片使用相同风格。
